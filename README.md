## ✨ Возможности

- 🎵 **Автоскачивание** — включаете видео на YouTube, трек сам появляется в библиотеке и скачивается в MP3
- 🎨 **Обложки** — постер YouTube или кадр из видео, с нормализацией размера
- 📝 **Тексты песен** — синхронизированные с воспроизведением, с подсветкой текущей строки
- 🎧 **Плеер** — shuffle, repeat, прогресс, громкость, перемотка по клику
- 📥 **Очередь загрузок** — статусы, прогресс, повтор ошибок
- 🗂️ **Оптимизация** — перекодирование MP3 с 320 kbps в V0 (~245 kbps) для экономии места
- ⚙️ **Настройки** — качество, обложки, прокси, cookies
- 🌙 **Тёмная тема** — в стиле Spotify
- 🔽 **Системный трей** — сворачивание, управление из трея
- 📊 **Логи с ротацией** — диагностика проблем

## 🚀 Установка

### Готовая сборка (рекомендуется)

1. Скачайте последний релиз из [Releases](https://github.com/cyberiaSword/yt-music-local/releases).
2. Распакуйте архив в удобное место.
3. Запустите `YTMusicLocal.exe`.
4. Установите Tampermonkey-скрипт (см. ниже).

### Из исходников

```bash
git clone https://github.com/cyberiaSword/yt-music-local.git
cd yt-music-local
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## 🔧 Настройка

### 1. Tampermonkey-скрипт (обязательно)

Приложение работает в связке с браузером через Tampermonkey.

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) в браузер.
2. Откройте панель Tampermonkey → «Создать новый скрипт».
3. Скопируйте содержимое файла `tampermonkey/video_bridge.user.js`.
4. Сохраните (`Ctrl+S`) и убедитесь, что переключатель зелёный.

### 2. Cookies YouTube (рекомендуется)

Для обхода bot detection YouTube требуются cookies.

1. Установите расширение **«Get cookies.txt LOCALLY»** в браузер.
2. Откройте youtube.com и авторизуйтесь.
3. Экспортируйте cookies в файл.
4. Сохраните как `data/cookies.txt` рядом с `.exe`.

### 3. Прокси (опционально)

Если у вас проблемы с доступом к YouTube:

1. Откройте `data/settings.json`.
2. Укажите прокси: `"proxy": "http://127.0.0.1:7897"`.

## ❓ FAQ

**Почему трек не скачивается?**
Возможные причины: нет cookies, прокси не работает, видео требует авторизации. Смотрите `data/logs/app.log`.

**Как обновить cookies?**
Экспортируйте заново через расширение «Get cookies.txt LOCALLY» и замените `data/cookies.txt`.

**Где хранятся скачанные треки?**
В папке `data/downloads/` рядом с `.exe`.

**Приложение падает при запуске.**
Проверьте `data/logs/app.log` и `startup.log` рядом с `.exe`.

**Как удалить библиотеку?**
Удалите папку `data/` — она полностью пересоздастся при следующем запуске.
